# Project instructions

- All authored code, documentation, reports and GitHub text must be in English.
- Preserve source names and required literal values, including non-English product names.
- This is an independent repository. Never stage changes in its parent repository.
- The user authorized commits and pushes after meaningful, verified milestones on 2026-11-03.
- Commit working deliverables, not empty commits or artificial activity.
- Never commit downloaded source rows, local lake contents, credentials or environment files.
- Use official Open Prices exports. No shop scraping is part of this project.
- Keep the target stack: Python, Data Lake, PySpark, Airflow and Greenplum.
- Distinguish implemented components from planned or unverified integrations.
- Preserve immutable source snapshots. Publish a completion manifest last.
- A missing observation does not prove a stockout or product deletion.
- Price comparisons must preserve currency, unit and observation grain.
- Run `python -m unittest discover -s tests -v` before committing behavior changes.
